# mockserver

Go-приложение для «злых» сценариев тестового стенда (ТЗ 4.4): тарпит,
медленные ответы, огромные тела, zip-бомба, обрыв соединения, бесконечные и
циклические редиректы, кривые TLS-сертификаты, cookies.

Исходный код: [`cmd/mockserver`](../../../cmd/mockserver) (общий Go-модуль
проекта, чтобы пользоваться линтером и тестами репозитория).

Образ собирается из `deploy/docker/Dockerfile.go` (target `mockserver`),
контейнер слушает `:80` (HTTP), `:443` (TLS по SNI) и `:8080` (healthcheck).

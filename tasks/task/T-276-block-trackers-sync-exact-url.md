# T-276: block_trackers — sync-зонд на семантике exact-URL из мержа moli #2729

## Контекст

T-275 перевёл зонды `blockLiveTrackerDomains` на async-XHR и оставил
sync-зонд (`probeSync('sync-xhr', 'http://c.clarity.ms:…/clarity-sync-probe')`)
движко-ветвленным под семантику НАШЕЙ версии PR
[lexmount/moli#2729](https://github.com/lexmount/moli/pull/2729):
«moli: sync-XHR уходит в сеть мимо паузы (#2728), 200 + счётчик ≥ 1»
(block_live_test.go:~495–500).

Мейнтейнер `ldm0` переработал ④ на голове PR-ветки (коммиты
`f3b01c908`, `8ff18ca02`, `53ff25d05`, 12.11.2026) — семантика изменилась:

- протокол вычисляет `synchronous_xhr_interception_patterns()` — точный
  список URL-паттернов, релевантных sync-XHR (матчит XHR-класс или
  type-less; CDP-auth ⇒ `["*"]`), и передаёт его вниз командой
  `SetFetchSubresourceInterception`;
- рендерер (`prepare_synchronous_xhr_request`) проверяет URL sync-запроса
  **и каждую цель редиректа** по этим паттернам: совпадение → отказ
  («Synchronous XMLHttpRequest interception is not supported»), нет
  совпадения → обычный сетевой путь.

Итог: **намеренная блокировка sync-XHR с матчащимся URL на moli теперь
работает** — parity с Chromium для трекер-зондов. Наш движко-ветвленный
кейс («moli: 200 в сеть») на новой семантике ложен: sync-зонд
c.clarity.ms матчит паттерн трекера → будет заблокирован на обоих
движках. Расхождение с Chromium остаётся только для «матчащийся URL,
который клиент продолжил бы» (path-trap-подобные) — это неотъемлемо
при невозможности паузы.

## Требования

1. После мержа #2729 в main moli: сверить финальную семантику по
   фактическим коммитам (мейнтейнер может дорабатывать; база анализа —
   `8ff18ca02`).
2. Схлопнуть движко-ветвление sync-зонда: оба движка ожидают блокировку
   (атрибут `error`, счётчик `claritySync == 0`); контроль (без
   блокировки) — `loaded 200` на обоих.
3. Обновить комментарии теста: расхождение #2728 эволюционировало из
   «sync-XHR всегда в сеть» в «exact-URL enforcement» (ссылки на #2729
   коммиты); path-trap-асимметрию для sync описать явно.
4. Прогон: интеграционная сборка moli с мержем #2729 (или релиз) —
   строка moli среза зелёная; chromium-строка без изменений зелёная.

## Критерии приёмки

- `TestEnginesLiveCDPSlice/{moli,chromium}/block_trackers` зелёные с
  едиными ожиданиями sync-зонда; `make test`/`make lint` зелёные.
- Комментарии в тесте соответствуют финальной семантике апстрима.
